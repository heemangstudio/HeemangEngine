# Retain complete host SFNT sources

Sparse TrueType sources caused 651 late completed frames in the preserved six-document seven-pair typing gate. Every late frame coincided with an outline refill, and every refill coincided with a late frame. The source-label diagnostic identifies real HANDotum, H2HDRM and HMKMM TrueType files, rather than stale requests. The previously accepted HFT retention already removed this path for the research report.

`add_host_font` now retains complete SFNT backing just as it retains complete HFT backing. Explicit sparse sources and `add_compact` keep their prior contracts. A complete source promotes an existing sparse face without changing face IDs or metadata, resets its face cache, preserves an owed relayout, and shares one TTC backing allocation. Repeated labels reuse complete sources and removal releases them. Studio reads complete sources for selected text faces, keeps metrics-only/default-only faces sparse, and promotes them only after actual outline requests. There is no character prewarm or new cache policy.
